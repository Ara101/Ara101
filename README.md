# 👋 Hi, I'm Lionel

*PhD student in Bioengineering, University of Washington · [Imoukhuede Lab](https://sites.bioe.uw.edu/imoukhuede/)*

I build computational and quantitative models of oxytocin receptor (OXTR) signaling — from
literature-scale parameter synthesis down to mechanistic simulation and ligand design.

## 👀 What I'm interested in

- **Kinetic meta-analysis** of Class A GPCR signaling, using Bayesian hierarchical and random-effects modeling
- **Biased agonist design**, combining generative modeling (DrugEx), multi-objective reinforcement learning, QSPR modeling, and structure-based docking against the OXTR cryo-EM structure
- **Mechanistic ODE modeling** of receptor signaling, built from a literature-curated kinetic parameter database
- **Reproducible scientific computing** — making the above run end-to-end on someone else's machine

## 🌱 Currently

Extending my work into deep generative models for molecular design, and preparing for my PhD general exam (Fall 2026).

## 💞️ Looking to collaborate on

Computational, systems-level modeling of biological systems, especially GPCR pharmacology and signal
transduction. Also happy to talk with anyone building parameter databases or doing meta-analysis in
pharmacology — that tooling is badly underbuilt.
